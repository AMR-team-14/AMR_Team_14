# AMR 14팀 인사이트 총정리와 최종 결론 (11/28)

팀 전체(진홍·민재·윤빈·승민)와 jsm 자동 실험의 결과를 합친 최종 정리. 비용이라 낮을수록 좋다.
점수는 팀 공통 평가기(`simulator/score.cjs`)로 다시 잰 값이다. 공개 = 시드 11–15(리더보드 성적), 1–500 = 시드 1–500 묶음(범용성).
출처: [진홍] 11/26 발표 정리·11/28 주말 탐색 공유, [민재] kmj 브랜치 insights·v3 보고서, [윤빈] yb 브랜치, [jsm] 자동 실험(`known-insights.md`, 보고서), [실험C] `reports/expC-transfer/`.
이 파일은 요청할 때만 갱신한다. 매 회차 바뀌는 숫자는 README 표와 `insights/TOP.md`를 본다.

## 0. 최종 결론 다섯 줄

1. **케이스마다 답이 두 벌이다.** 공개 시드 5개에서 가장 낮은 답(리더보드용)과 시드 1–500에서 가장 낮은 답(범용용)이 다섯 케이스 모두 다르다. 리더보드용은 다른 시드에서 2–21점 나쁘고, 범용용은 공개 시드에서 4–60점 나쁘다.
2. **범용적인 것은 절차이지 나무가 아니다.** 같은 탐색 절차(통로 → 대수 → 나무 → 경계값)가 다섯 지도에서 기준선보다 18–51% 낮은 답을 만든다. 하지만 1위 나무를 다른 케이스에 그대로 옮기면 3–38% 나빠진다.
3. **답의 뼈대는 하나다.** 맨 위에서 "방금 들어온 주문인가"(`w`)를 가르고, 그 가지에 "특정 주문에는 일부러 먼 빈 차를 보낸다"(`de,max`)를 둔다. 빈 차를 옮기는 기능이 없는 제출 형식에서 이것이 유일한 재배치 수단이다.
4. **점수를 가장 크게 움직인 것은 통로 방향, 그다음이 대수, 마지막이 경계값이다.** 경계값 다듬기는 공개 시드 전용 이득이라 다른 시드에서 사라진다.
5. **막힐 때 필요한 것은 더 오래가 아니라 다른 종류의 이동이다.** 순환 통째 뒤집기, 대기 가지 재전수, 후보 경계값 구멍 메우기, 방향 줄 세우기 기준 바꾸기가 모두 바닥을 깼다. 같은 이웃을 수천만 번 더 본 것은 하나도 못 깼다.

## 3. 케이스별 결론

### Case 1 (통로 고정, 비공개 시드 채점)
- 21대 · 루트 `w` 경계 0.001대. 공개 1170.20 답은 1–500에서 1184.05로, 공개 점수로 고르면 안 된다. 최종 후보는 1–500 최저 답(jsm 1180.56, 진홍 1180.70).
- 형식 안의 바닥에 가깝다(G10). 3·5노드로 줄이면 15–32점 나쁘다[윤빈].

### Case 2 (격자)
- 공개: 24대, 강연결 방향 61,536개 중 "다듬은 나무로 줄 세운" 2위 방향 → 613.16[진홍]. 1–500에서는 626.62로 크게 나쁘다.
- 강건: 24–25대 D2 계열 urg 뿌리 작은 나무가 605대[윤빈], jsm robust ILS 603.48. 공개는 638–663.
- 두 목표의 차이가 가장 큰 케이스다(공개용은 1–500에서 +13, 강건용은 공개에서 +25~50).

### Case 3 (OHT형 루프)
- 방향 54개 전수, D1(1111111100000000011111011001101)·22대가 양쪽 다 최선 계열.
- 공개: 962.70 → jsm 자동 실험 962.45(루트 경계 0.03, 대기 가지·긴급 반경 40) → 진홍 962.28(루트 0.031, 대기 가지를 빈 차 거리 160m 기준 긴급 여부로).
- 강건: 민재 v3 974.54가 최저이고 공개 974.43과 거의 같다(과적합 없는 답). U95 꼬리의 57%가 교차로 연쇄 정체·S8 주차 진공[민재].

### Case 4 (교차로 고밀도)
- 18대가 최적(17대는 1,000시드에서 +4.8)[jsm].
- 순환 통째 뒤집기 + 크게 차기로 새 방향 계열 → 788.95[진홍]. 이 답은 1–500 793.45로 예외적으로 강건.
- 강건 최저는 jsm 790.42, 민재 v3 791.55. 비용의 86%가 교차로 고정 통과[민재].

### Case 5 (저밀도 병목)
- 공개: 23대 D1, 상위 답들이 0.55 안에 몰려 포화(770.82)[진홍][jsm].
- 강건: 22대 D2 계열 — jsm 774.78, 진홍 주말 775.05, 민재 v3 775.71. 공개 1위(23대)보다 11점 좋다.
- A-S1 주차 진공이 U95 꼬리의 52%[민재]. 22→23대 −11.8, 23→24대 −1.8(1,000시드)[jsm].

## 4. 방법론 결론 (발표용)
- **탐색 파이프라인(진홍)**: 엔진 대조 → 기준선 → 방향 후보(Gurobi/전수) → 시뮬 재순위 → 공개 점수 직접 탐색 → 구조 훑기 → 이식 → 경계 훑기 → 형식·반려 검사 → 웹 대조. 개선의 95–99%가 여기서 나왔다.
- **자동 실험 루프(jsm)**: 팀 전체 답안을 공통 평가기로 매번 재채점 → 코드가 통계·두 순위 → AI(Opus)가 해석하고 다음 실험(ILS/탐색/평가)을 제안 → 코드가 상한을 걸어 GitHub Actions에서 실행. 사람 개입 없이 11/27–28 동안 약 15회차를 돌아 공개 2건(C3·C4 근접), 강건 4건(C1·C2·C4·C5) 팀 기록을 냈고, 진홍의 Case 3 962.28은 이 루프가 찾은 답에서 출발했다.
- **강건성 검증(민재)**: 탐색에 쓰지 않은 시드(3001–3500, 5001–5500)로 확인. 독립 시드 절감폭이 1–500 절감폭 이상이면 과적합이 아니다.
- 공통 교훈: 판정은 웹과 같은 엔진이 하고, 사람·AI는 무엇을 볼지만 정한다.

## 5. 남은 결정 (12/2 회의)
1. **최종 제출 = 공개용 유지?** 채점이 공개 시드 5개라면 공개용(강건 답으로 바꾸면 9–25점 손해). 다른 시드도 본다면 강건용. [진홍 제안: 공개용 유지, 강건 답은 발표 자료]
2. **답 파일 공유 방식**: 리포가 공개라 진홍은 답을 리포 밖으로 전달 중. jsm 자동 실험은 저장소 답만 보므로 788.95·770.82·613.16·962.28은 순위에 없다.
3. **발표 주장**: "리더보드 1위"보다 "범용 절차 하나 + 케이스별 두 벌의 답"이 근거가 강하다(G5·G6·G7).
4. **Case 1 공유 나무**(한 기준을 두 갈래가 가리킴)가 형식 위반인지.
