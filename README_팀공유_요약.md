# AGV 운영 규칙 설계 최적화 · 팀 공유 패키지 안내

## 1. 핵심 최적화 파이프라인 (`agv_opt.cpp`)
* **완전 독립형 C++20 단일 엔진:** 외부 의존성 없이 `agv_case_data (1).json`과 `agv_dispatch_log_seed11 (1).csv`를 직접 파싱하며, `Mulberry32` 난수 생성기·Dijkstra 최단경로·동일시각 일괄처리(`abs(dt) < 1e-9`)·교차로 FIFO를 웹 시뮬레이터와 9-노드 기준 770연속 배차 0오차 일치로 구현했습니다.
* **핵심 고속화 기법:**
  1. **비교차로 경로 압축(`COMP_PATH`):** 중간 직선 노드 이벤트를 합쳐 힙 연산 최소화
  2. **플로우 헤드 & 위치 대표 지배성:** 동일 출발지·목적지 플로우와 동일 노드 대기 AGV 중 지배 불가능한 쌍 제거
  3. **`w min` 이분탐색 지배성:** `w min` 노드가 있어도 큐 전체를 스캔하지 않고 임계값 경계 요청만 $O(\log Q)$ 탐색 (`--verify` 기준 브루트포스와 `0.000000000` 일치)
  4. **멀티스레드 병렬 검증 (`parallel_for`):** `12`스레드 기준 800시드 검증 약 1.3초
* **지원 CLI 모드:**
  - `agv_opt.exe --eval <csv>`: 공개 5시드 채점
  - `agv_opt.exe --eval100 <csv>`: 공개 5시드 + `u50(101..150)` + `held50(151..200)` 교차검증
  - `agv_opt.exe --eval300 <csv>`: 미접촉 `HELD300(201..500)` 검증
  - `agv_opt.exe --eval800 <csv>`: 미접촉 `HELD300 + NEW500(201..1000)` 800시드 전체 검증
  - `agv_opt.exe --verify <csv>`: 제약조건(`dir`, `fleet`, `tree`) + 브루트포스 15스트림 정합성 검증
  - `agv_opt.exe --analyze <csv>`: 대수 민감도(`n=16~23`), 노드 Ablation, 경계값 민감도 분석
  - `agv_opt.exe --polish <in.csv> [out.csv]`: 2단계 좌표 미세 탐색
  - `agv_opt.exe --reconstruct [seed.csv]`: GP 구조 재구성 탐색

## 2. 현재 성과 및 최적성 판정
* **최종 제출 1순위 (`n=19`, 최저 분산):** **`answer_final_best.csv`**
  - **웹 실측 점수: `1,185.42 천원/시간`** (기존 리더보드 1위 `1,198.16` 대비 **`-12.74점` 돌파**)
