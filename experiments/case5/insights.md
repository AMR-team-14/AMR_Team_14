# Case 5 실험 메모

대기 가지를 1~3노드로 처음부터 열거하고 후보의 이웃을 다시 탐색해 23대에서 공개 점수 770.94를 얻었다. 기존 기록의 새 200묶음에서는 평균 785.76, 반려 0이었다. [상세 로그와 분석](original/jinhong/case5/NOTES.md)

## 공통 평가기 재채점 (11/25, [PJH-1125-77094](PJH-1125-77094/))

- 리더보드 제출안(23대, 770.94, 11/25 00:10 제출)은 시드 11~15에서 770.9353, 시드 1~500에서 786.45, 반려 0이다. 이전 제출안(771.43 안)은 같은 조건에서 787.15다.
- 방향 648개 전부를 대수 20~26으로 훑었지만 다른 계열은 없었다. 이웃 탐색이 멈췄을 때 대기 가지를 처음부터 다시 짜고 이웃 탐색을 하면 다른 바닥이 나온다. [상세 기록](https://github.com/AMR-team-14/AMR_Team_14/blob/jinhong-experiments/jinhong/case5/NOTES.md)
- 탐색에 쓴 시드는 11~15다.
