# Q01 오래된 적체 예외 실험

**기존 19대·9노드 제출안을 유지한다.** 고정한 예외 구조의 선택용 500시드에서 `T=19.90분`과 `19.95분`이 공동 최저였고, 동률이면 작은 값을 사용하는 규칙에 따라 `19.90분`을 확정했다. 신규 3,600시드에서 예외 규칙 자체의 비용 절감은 확인되지 않았고, 기존 제출안보다 3.26점 비쌌다.

## 1. 가설과 비교 트리

가설은 **공차 65m 이하이고 출발지에 대기 요청이 2건 이상 쌓인 경우, 오래 기다린 일반 요청의 순서를 앞당기면 비용이 줄어든다**는 것이다. `qo`는 출발지의 미배정 요청 건수, `w`는 개별 요청이 배차를 기다린 시간이다. `w > T`를 만족하는 그룹을 우선하며, 같은 그룹 안의 기본 순서는 공차 거리, 도착 순서, 차량 번호다. 근거리 긴급 우선과 원거리 규칙은 세 안에 공통이다.

| 안 | 근거리·다중대기·긴급 | 근거리·다중대기·일반 |
|---|---|---|
| ① 기존 9노드 제출안 | `w ≤ 2.45` 그룹 우선 | 기본 순서 |
| ② 8노드 대조안 | `w ≤ 2.45` 규칙 제거 | 기본 순서 |
| ③ 9노드 예외안 | ②와 같음 | `w > T` 그룹 우선 |

**③−②는 예외 규칙의 순수 효과**, **③−①은 노드 한도를 지키면서 실제로 제출안을 바꿨을 때의 효과**다. 모든 비교에서 19대를 고정했다.

## 2. T를 고른 방법

- **초기 탐색 240시드(31001–31240).** 0~12분을 0.25분 간격으로 보고 13·14·16·20·24분도 포함했다. 총 54개다. ②와 결과가 달라지고 비용이 낮았던 상위 5개 지점 주변을 ±0.25분 범위에서 0.05분 간격으로 좁혀, 서로 겹치지 않는 41개를 추가했다.
- **선택 500시드(32001–32500).** 초기와 정밀 탐색에서 유망한 값과 처음 설명에 쓴 4분을 포함해 13개를 재평가했다. 실격이 없고 ②와 결과가 달라진 값 중 평균 비용이 가장 낮은 값을 확정했다. 순위에는 공식 목적함수와 같은 비용식을 사용했다.
- **최종 검증 3,600시드(33001–36600).** 확정한 19.90분만 ①·②와 동일한 요청 목록에서 짝비교했다. 제출안을 바꾸려면 실격 0건과 두 비교에서 평균 비용 절감 폭이 표준오차의 2배를 넘는 조건을 모두 만족해야 한다.

| T | 선택 500시드 ③−② | 선택 500시드 ③−① | ②와 비용이 달라진 시드 |
|---:|---:|---:|---:|
| 4.00분 | +0.497 | +3.736 | 500 / 500 |
| 19.90분 | −0.036 | +3.203 | 17 / 500 |
| 19.95분 | −0.036 | +3.203 | 17 / 500 |

19.90분은 **이 탐색에서 선택된 임계값**이다. 연속적인 모든 임계값의 최적성을 입증하거나, 19.90분과 19.95분을 구분할 수 있는 결과는 아니다. [전체 탐색표](results/thresholds.csv)

## 3. 신규 3,600시드 결과

| 안 | 평균 비용 | 전체 평균 픽업 대기(분) | 긴급 픽업 P95(분) | 비용이 높은 5%의 평균 | 실격 |
|---|---:|---:|---:|---:|---:|
| ① 기존안 | **1,191.705** | 3.7885 | **5.1937** | **1,217.081** | 0 |
| ② 8노드 대조안 | 1,194.985 | 3.7888 | 5.2261 | 1,221.175 | 0 |
| ③ 예외안, T=19.90분 | 1,194.962 | 3.7887 | 5.2260 | 1,221.287 | 0 |

| 짝비교 | 비용 차이 ± 표준오차 | 판단 |
|---|---:|---|
| ③−② | −0.023 ± 0.032 | 예외 규칙의 개선은 확인되지 않음. ②와 비용이 달랐던 시드는 148/3,600개(4.1%). |
| ③−① | +3.257 ± 0.134 | 기존안보다 비용이 높아 교체하지 않음. |
| ②−① | +3.280 ± 0.132 | 기존 긴급 분기의 자리를 비우는 것만으로 비용이 증가. |

비용의 단위는 천원/시간이며 차이가 음수면 개선이다. 상위 5% 비용은 안별로 가장 비용이 높았던 180개 시나리오의 평균이다. 이 지표도 ③이 ①보다 4.21점 높았다. ②에서 늘어난 비용 대부분은 기존 긴급 대기 규칙을 빼면서 긴급 P95가 0.0325분(약 1.95초) 늘어난 데서 왔다.

## 4. 재현

팀의 실험별 폴더 구조를 따라 `run.json`, `trees/`, `results/`에 조건과 결과를 정리했다. 이 폴더의 실행기는 `younbean`의 C++ 시뮬레이터를 사용하며 트리 CSV에는 `dir`과 `fleet` 행도 포함한다. 결과표는 실행기가 생성했다.

저장소 루트에서 Visual Studio 개발자 PowerShell로 실행한다.

```powershell
cl /nologo /std:c++20 /O2 /EHsc /utf-8 agv_opt.cpp /Fe:agv_opt.exe
.\agv_opt.exe --yb-aged-backlog answer_final_best.csv q01-reproduced
.\agv_opt.exe --verify q01-reproduced/trees/01_baseline.csv
.\agv_opt.exe --verify q01-reproduced/trees/02_budget_control.csv
.\agv_opt.exe --verify q01-reproduced/trees/03_aged_backlog.csv
```

세 트리 모두 제약 검사를 통과했고, 각 트리의 빠른 평가와 전수 배차 쌍 평가 비용은 15개 시드에서 일치했다. [실험 코드](../../../agv_aged_backlog.hpp) · [정책별 요약](results/summary.csv) · [짝비교 결과](results/comparisons.csv) · [시드별 원본](results/validation_by_seed.csv.gz)
