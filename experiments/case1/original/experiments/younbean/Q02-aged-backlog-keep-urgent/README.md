# Q02 긴급 규칙을 유지한 오래된 적체 실험

**공식 제출안은 그대로 유지한다.** Q01에서는 근거리 긴급 규칙을 제거하는 비용과 일반 요청 예외의 효과를 구분했지만, 기존 9개 규칙을 모두 유지한 상태도 볼 필요가 있었다. 이번에는 시뮬레이션에서 일반 요청 예외 한 개만 가상으로 더한 경우와, 9노드 한도를 맞춘 제출 가능안을 각각 검증했다. 새 3,600시드에서 둘 다 기존안보다 비용이 낮다는 근거가 없었다. 다만 4분 예외는 늦은 일반 픽업을 줄이는 대신 평균 비용을 높여 운영상 교환관계가 드러났다.

## 가설과 트리

공차 65m 이하인 후보 중 출발지에 대기 요청이 2건 이상 쌓인 경우를 본다. 기존처럼 **긴급 여부를 먼저 비교**하고, 일반 요청끼리만 비교하는 마지막 가지에서 `w > T`인 쪽을 우선한다. 근거리 긴급 요청의 `w ≤ 2.45분` 기준은 모든 비교에서 유지했다.

| 안 | 무엇을 바꿨나 | 해석 |
|---|---|---|
| 01 기존 제출안 | 19대, 9노드 | 기준 |
| 02 8노드 대조안 | 기존 9번, 원거리·다중대기·단기 대기 그룹의 긴급 우선 규칙만 제거 | 9노드 한도로 자리를 비우는 비용 |
| 03·05 가상 예외안 | 01의 모든 규칙을 유지하고 일반 요청 가지에 `w > T` 조건 추가 | 예외의 순수 효과. 논리상 10노드로 진단용 |
| 04·06 제출 가능 예외안 | 02의 빈자리를 일반 요청 가지에 배치하고 `w > T` 조건 추가 | 예외와 자리 비용을 모두 반영한 9노드 정책 |

가상 노드는 시뮬레이터에서 대상 가지의 우선순위에 실제 `w,max` 노드와 같은 순위 비트를 더한다. 공식 CSV를 생성하지 않는다. 8노드 대조안의 가상 노드와 실제 9노드 후보를 같은 15개 시드에서 비교했고, 우선 가능한 쌍을 전부 보는 평가와 빠른 평가의 점수도 일치했다.

## T 선정과 검증

- 탐색용 320시드(37001–37320)에서 15개 기준값을 비교했다. 비용이 낮고 대조안과 결과가 달라진 상위 3곳 주변을 ±0.25분 범위, 0.05분 간격으로 확인해 각 구조에서 30개를 추가했다.
- 별도 600시드(38001–38600)에서 구조별 13개 값을 비교했다. 실격이 없고, 대조안과 결과가 달라지는 후보 중 평균 비용이 가장 낮은 값을 고정했다. 가상안은 **0.45분**, 제출 가능안은 **1.50분**을 선택했다.
- 신규 3,600시드(39001–42600)에서 각 정책을 같은 요청 목록으로 짝비교했다. `T=4분`은 임계값 선정과 별도로 미리 정한 운영 예시다.
- 평균 비용과 긴급 픽업 P95 외에, 일반 요청 1,000건당 **픽업까지 8분을 넘긴 건수**를 측정했다. 워밍업 이전 요청과 종료 전 마지막 8분에 들어온 요청을 제외했고, 8분 안에 픽업되지 않은 요청은 지연으로 셌다. 8분은 비교를 위한 지표다.

## 신규 3,600시드 결과

| 후보와 비교 대상 | 평균 비용 차이 ± 표준오차 | 8분 넘게 기다린 일반 요청 차이 (1,000건당) |
|---|---:|---:|
| 02 대조안 − 01 기존안 | +0.972 ± 0.200 | −0.853 |
| 03 가상 최선(0.45분) − 01 기존안 | −0.071 ± 0.173 | +0.016 |
| 04 제출 가능 최선(1.50분) − 02 대조안 | +0.272 ± 0.203 | −0.253 |
| 04 제출 가능 최선(1.50분) − 01 기존안 | +1.244 ± 0.201 | −1.106 |
| 05 가상 4분 − 01 기존안 | +0.551 ± 0.198 | −0.490 |
| 06 제출 가능 4분 − 01 기존안 | +1.862 ± 0.199 | −1.155 |

비용 단위는 천원/시간이며 모든 차이는 후보에서 비교 대상을 뺀 값이다. 여섯 안 모두 실격 0건이었다. 각 안의 평균 비용, 긴급 픽업 P95, 고비용 상위 5% 평균은 [정책 요약](results/summary.csv)에 있다.

**판단.** 기존 규칙을 전부 둔 상태에서도 선택된 예외안의 0.071점 절감은 표준오차 0.173점보다 작았다. 4분 기준은 일반 요청 1,000건당 긴 지연을 약 0.49건 줄였지만 비용이 0.55점 높았다. 제출 가능 최선안에서 보이는 1.11건 감소는 새 규칙과 원거리 긴급 규칙 제거가 함께 만든 변화다. 대조안과 비교하면 새 규칙의 몫은 약 0.25건 감소이고, 비용은 낮아지지 않았다. 현재 과제의 총비용 기준에서는 01을 유지한다.
