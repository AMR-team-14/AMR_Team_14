# U01 긴급 루트의 2층 전수 비교

- 담당: 장승민
- 계열 / 부모: U / U0 `urg(max,0.5)`
- 상태: 계획

## 가설

U0는 긴급 p95를 기준안 수준으로 낮추지만 평균 대기가 길다(B2). 일반 가지(lo) 또는 긴급 가지(hi)에 규칙 하나를 붙여 그 손실을 줄일 수 있는가.

## 조건

- 트리 56개: U0 + lo 확장 39개(`de(max)` 9, `dl` 8, `w` 14, `qo` 8) + hi 확장 16개(`de(max)` 9, `w(min)` 7)
- 자동 제거: 말단 `de(min)`, 긴급 가지의 `dl`(A1)·`w(max)`(A4)·`qo`(A2)
- 대수 18·19·20, 시드 1001~1005, 기준 U0 (168회 평가)
- `trees/index_1lo.csv`, `index_1hi.csv`에 트리 표기

## 판단

반려 없이 U0보다 싼 후보 중 구조가 다른 것 최대 5개를 U02(3층 확장, 16시드)로 넘긴다. 개선이 없으면 그 사실 자체를 B2의 근거로 기록한다.
