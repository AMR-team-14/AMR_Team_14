# Case 3 실험 메모

루프 방향 후보를 비교하고 방향별 차량 및 배차 규칙을 다듬었다. 기존 로드맵의 공개 점수는 962.70이다. [상세 로그와 분석](original/jinhong/case3/NOTES.md)

## 공통 평가기 재채점 (11/25, [PJH-1124-96270](PJH-1124-96270/))

- 리더보드 제출안(22대, 962.70)은 시드 11~15에서 962.7048, 시드 1~500에서 978.14, 반려 0이다. 공개 시드와 15.4 차이가 나므로 공개 시드에 맞춘 몫이 크다.
- 방향은 그대로 두고 나무만 바꿨다(긴 주문 재배치, 긴급 주문이 가까운 차를 아끼게 함). [상세 기록](https://github.com/AMR-team-14/AMR_Team_14/blob/jinhong-experiments/jinhong/case3/NOTES.md)
- 탐색에 쓴 시드는 11~15다.
