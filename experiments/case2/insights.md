# Case 2 실험 메모

## 5노드 후보 비교 · 시드 1~50

팀원이 공유한 강연결 통로 방향 3개를 사용했다. `pjh` 6노드 축소안과 기존 `jsm` 5노드 답안은 두 방향에서 교차 평가했다. `jsm` 3노드에서 긴급·비긴급 분기를 하나씩 추가한 4개와 `kmj` 9노드의 모든 루트 연결 5노드 축소안 10개는 각각 원래 방향에서 평가했다. 20개 트리·방향 후보에 23~26대를 적용한 80개 조합은 모두 반려 0/50이었다.

| AGV 대수 | 5노드 최저비용 후보 | 비용 (천원/시간) |
|---:|---|---:|
| 23대 | `GROW-WW` | 624.0613 |
| 24대 | `GROW-WQ` · `GROW-DQ` | 604.5419 |
| 25대 | `GROW-WQ` | 606.5037 |
| 26대 | `SHARED-5` | 614.4997 |

- 24대 `GROW-WQ`와 `GROW-DQ`가 공동 1위였다. 두 답안은 긴급 요청에 적용하는 4번 노드만 다르며, 시드 1~50에서는 배정 건수와 해시가 일치했다. 같은 방향과 대수의 기존 3노드는 604.7421천원/시간으로, 5노드 공동 1위보다 0.2002 높았다.
- 같은 트리와 대수를 유지한 교차 비교에서 `SHARED-5`는 24대에서 `jsm` 방향이 `pjh`보다 8.2053 낮았다. `PJH-12345`는 방향만 동일하게 바꿨을 때 421.9868 높아졌다. 비교한 방향별 효과는 트리에 따라 달랐다.
- 순위는 선정한 세 방향, 23~26대, 시드 1~50 탐색 범위의 결과다.
