대상 해: [answer_final_best.csv](./answer_final_best.csv) (`n=19`, 9노드, 웹 `1,185.42`)

## 1. 결론

| 주장 | 판정 | 근거 요약 |
|---|---|---|
| 노드 1개 변경 기준 ε-국소최적 (ε ≈ 1점) | **선언 가능** | 이웃 해 전수 확인, 상위 후보 800시드 재검증 |
| 노드 2개 동시 변경 기준 국소최적 | **아직 불가** | 2노드 이웃은 샘플링(라운드당 약 950개)만 함 |
| 전역 / 준-전역 최적 | **불가** | 탐색 범위가 극히 작고, 처음부터 키우는 탐색이 기존 해조차 재발견 못함 |

> [!IMPORTANT]
> 현재 정당하게 쓸 수 있는 표현은 **"노드 1개 변경 기준 ε-국소최적(ε≈1천원/시간)인 평탄한 구간"**까지입니다. "local minimum"을 엄밀하게 선언하려면 2장의 한계를 해소하는 **방법 A**가 필요합니다.

## 2. 현재 증거의 한계 (이전 표현 정정 포함)

### 2.1 "유토피아 하한 1,184.4"는 하한이 아님
- 순수 STTF 정책의 W̄ 값과 긴급 우선 휴리스틱의 U95 값을 더한 것일 뿐, 어떤 정책도 더 낮출 수 없다는 증명이 아닙니다.
- 같은 방식의 `n=18` "하한"은 `1,170.5`인데, 현재 `n=18` 결과는 `1,190.99`로 20점 차이가 납니다. 이 논리로는 최적성을 보장할 수 없습니다.

### 2.2 탐색 범위
- 노드 9개 트리 공간은 대략 10¹⁵ 규모입니다(트리 모양 4,862개 × 분기 규칙 약 22⁹).
- 실제 탐색량은 30,705개(로그 기반 수술 596개 + 5트랙 심층 30,109개)로 극히 일부입니다.

### 2.3 전역 탐색 방법 자체가 약했음
- 처음부터 1→9노드로 키우는 빔서치(Track 2, `de min 65` 루트)의 최고값은 `train100 = 1,208.21`(n=19)이었습니다. 기존 해(`1,189.71`)보다 18점 나쁩니다.
- 기존 해도 다시 찾지 못한 방법에서 더 좋은 해가 안 나왔다는 사실은 "더 좋은 해가 없다"는 근거로 약합니다.

### 2.4 검출력 한계
- 1차 선별을 12시드로 했고, 상위 k개만 다음 단계로 넘겼습니다. 1점 미만의 실제 개선은 노이즈에 묻혀 탈락했을 수 있습니다.
- 마지막 800시드 검증은 가짜 개선(false positive)은 걸러내지만, 이렇게 놓친 개선(false negative)은 되살리지 못합니다.

### 2.5 웹 점수 비교는 구조 우열의 증거가 아님
| 정책 | 웹 5시드 | 800시드 기대값 |
|---|---:|---:|
| `n=19` [answer_final_best.csv](./answer_final_best.csv) | `1,185.42` | `1,191.27 ± 11.18` |
| `n=18` `answer_final_best_n18.csv` | `1,193.14` | `1,190.99 ± 12.60` |

- 기대값 차이는 n=18이 `-0.28`점 더 좋습니다(짝비교 `t=-0.59`, 동률).
- 짝비교 차이의 표준편차는 약 13.4이므로 5시드 표준오차는 약 6.0입니다. 웹 차이 7.7점은 z≈1.3 수준의 정상 노이즈입니다.

## 4. 방법 A (권장): 노드 2개 변경 이웃 전수 검사

### 4.1 목표
통과 시 **"노드 2개 변경 기준 ε-국소최적 (ε = 0.5점, 95% 신뢰)"**을 엄밀하게 선언합니다.

### 4.2 이웃 정의 (`n=18`, `n=19` 각각)
| 이웃 종류 | 내용 | 규모(유효성 필터 전) |
|---|---|---:|
| N1 재확인 | 노드 1개를 분기 규칙 집합 S(22종)로 교체 | 9 × 22 = 198 |
| N2 쌍 교체 | 노드 2개를 동시에 S로 교체 | 36 × 22² = 17,424 |
| 구조 이동 | 잎 재배치(임의 빈 자리 × S), 형제 하위트리 교환, 부모-자식 교환 | 수백 개 |
| `w` 쌍 미세조정 | `#6`, `#8` 임계값 ±0.05 ~ ±0.20 동시 조정 | 약 80 |

### 4.3 통계 프로토콜 (상위 k개 상한 없이 임계값으로 통과)
모든 후보를 **같은 시드 집합**(공통 난수)에서 현재 해와 짝비교합니다.

| 단계 | 시드 | 통과 조건 (현재 해 대비 짝비교 차이 d) |
|---|---|---|
| 0. 검출력 설계 | 랜덤 이웃 50개 × 100시드 | 짝비교 표준편차 σ_d 추정 → 0.5점 검출(검정력 0.8)에 필요한 시드 수 결정 |
| 1. 선별 | train 30시드 | d < +2.0 |
| 2. 정밀 | train 100시드 (Seeds 101..200) | d < +0.5 또는 단측 95% 하한 < 0 |
| 3. 검증 | HELD300 (Seeds 201..500) | d < 0 이고 t < −2 |
| 4. 최종 확인 | **완전 신규 800시드 (Seeds 1001..1800)** | d < 0 이고 t < −2, 실격 0 |

- 4단계에 신규 시드를 쓰는 이유: 기존 HELD300/500은 이미 여러 차례 선택에 쓰여 오염되었을 수 있기 때문입니다.

### 4.4 예상 소요
- 실측 처리량: 약 600 시뮬/초 (12스레드, 11개 × 800시드 = 14.5초 기준).
- 1단계: 약 1.8만 개 × 30시드 ≈ 52만 시뮬 ≈ n당 약 14분.
- **총 30~50분 예상** (n=18, 19 합계, 조기종료 적용 시 단축).

### 4.5 결과 해석
| 결과 | 조치 |
|---|---|
| 4단계 통과 후보 없음 | "노드 2개 변경 기준 ε-국소최적(ε=0.5, 95%)" 선언 |
| 통과 후보 있음 | 새 기준해로 교체 후 A 반복. 루트 승격은 [agent.md](./agent.md) 기준(신규 시드에서 유의한 우위, 실격 0, 브루트포스 정합성 `0.000000000`)을 만족할 때만 |

## 5. 방법 B (선택): 전역 탐색 신뢰성 확인

### 5.1 목표
"탐색 방법이 기존 해를 스스로 재발견할 수 있는가"를 먼저 확인합니다. 재발견이 되어야 "그 방법으로 더 좋은 해를 못 찾았다"가 의미를 가집니다.

### 5.2 설계
- 무작위 유효 9노드 트리에서 출발하는 독립 진화 탐색(GP) 20회.
- 개체 200, 세대 약 30, 적합도는 공통 난수 30시드, 하위트리 교차 + 변이.
- 기록 지표: **재발견율** = 기존 해 대비 1점 이내에 도달한 실행 비율.

### 5.3 해석
| 재발견율 | 의미 |
|---|---|
| 높음 + 더 좋은 해 없음 | 전역 관점의 실질적 근거 확보 |
| 높음 + 더 좋은 해 발견 | 방법 A 프로토콜로 검증 후 승격 검토 |
| 낮음 | 탐색 방법이 약함 → 아무 결론도 내릴 수 없음 |

### 5.4 예상 소요
20회 × 200개 × 30세대 × 30시드 ≈ 360만 시뮬 → **약 2~3시간**.

## 7. 보고서용 문장

**현재 증거 기준:**
> 제안한 정책은 노드 1개 변경 기준 ε-국소최적(ε≈1천원/시간)인 평탄한 구간에 위치하며, 미접촉 800시드에서 기대비용 1,191.27 ± 0.40, 실격 0/800을 기록했다. 탐색한 30,705개의 다른 구조는 모두 통계적으로 유의하게 열세였다(t ≥ 2.26).

**방법 A 통과 시:**
> 제안한 정책은 노드 2개 동시 변경까지 포함한 이웃 전체에서, 공통 난수 짝비교와 신규 800시드 검증 기준 0.5천원/시간 이상 개선되는 해가 존재하지 않는 ε-국소최적해(95% 신뢰)이다.
