# 실험 전 확인할 파일

| 파일 또는 화면 | 확인할 내용 |
|---|---|
| 수업 배포 IE325_팀프로젝트_평가안내.pdf, 해당 케이스 공식 채점 화면 | 제출 형식과 규칙, 공개 시드, 제출 한도 |
| simulator/spec/cN.json | 케이스 ID, 간선 순서, 고정 방향, 차량 범위 nMin·nMax, maxNodes, 평행 차선 설정, 반려 기준 |
| simulator/internal/inputs.json | 공통 평가기에 고정한 케이스 입력과 기준 답안. spec과 일치하는지 확인 |
| simulator/score.cjs, simulator/internal/jsim.cjs | 사용한 버전, 요청 생성, 점수 합산과 반려 판정 |
| 실험 폴더의 answer.csv | dir의 길이·순서·고정 방향·강연결·평행 차선 제약, fleet의 허용 범위, key의 허용 변수·연산자·임계값, 루트·자식 참조·노드 수·순환 여부 |
| 실험 폴더의 run.json | 케이스, 답안 해시, 입력 해시, 평가기 버전·옵션, 집계 방식, 최종 검증 시드 1~500 |

공식 화면과 저장소의 입력에 차이가 있으면 해당 항목을 확인한 뒤 결과에 이유를 남긴다. 공통 평가기 실행만으로 공식 제출의 모든 형식 제약을 확인했다고 기록하지 않는다.
