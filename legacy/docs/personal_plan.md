# **AGV 배차 최적화 프로젝트 — 개인 기여 계획**

**핵심 목표:** 팀원이 개발한 1185점 최적화 알고리즘을 바탕으로, 문제의 구조를 명확히 설명하고, 기존 정책 대비 개선 효과를 통계적으로 검증하며, 알고리즘의 설계 근거를 논리적으로 분석한다.

단순히 높은 점수를 얻었다는 결과를 제시하는 것이 아니라, **왜 어려운 문제인지, 무엇이 개선되었는지, 왜 이러한 최적화 접근이 효과적이었는지** 설명하는 것이 세 가지 계획의 공통 목표다.

## **1. 문제 구조 분석 및 발표용 설명 자료 제작**

Problem Formulation & Analysis

**목적:** AGV 배차 문제를 처음 접하는 사람도 문제의 구조, 의사결정 요소, 제약조건, 최적화의 어려움을 이해할 수 있도록 정리한다.

### **세부 내용**

| 분석 항목      | 주요 내용                                 |
| ---------- | ------------------------------------- |
| ① 시스템 구성   | 물류센터의 작업 구역, AGV, 주문, 이동 경로 및 교차로 구조  |
| ② 문제 발생 과정 | 주문 발생부터 AGV 배정, 이동, 픽업, 배송까지의 과정      |
| ③ 의사결정 요소  | AGV 운영 대수, 배차 우선순위, 결정나무의 조건과 기준값     |
| ④ 목적함수     | AGV 운영 비용, 평균 대기시간, 긴급 주문 P95 사이의 관계  |
| ⑤ 제약조건     | AGV 이동 경로, 교차로 점유, 처리 능력, 정책 구조 등의 제한 |
| ⑥ 최적화의 어려움 | 주문 발생의 불확실성, AGV 간 상호작용, 상충하는 성능 지표   |
| ⑦ 핵심 쟁점    | 가까운 주문과 오래 기다린 주문 중 무엇을 우선해야 하는가?     |

### **핵심 질문**

- 우리는 정확히 무엇을 결정할 수 있는가?
- 왜 가장 가까운 AGV를 배정하는 것만으로는 충분하지 않은가?
- 왜 단순한 수리적 계산보다 시뮬레이션이 필요한가?
- 운영 비용과 서비스 수준 사이에는 어떤 상충관계가 존재하는가?

**예상 산출물:** 문제 구조 분석 Markdown 문서, 시스템 흐름도, 목적함수 및 결정나무 설명 자료, 발표용 슬라이드.

## **2. 네 가지 배차 정책의 통계적 비교 분석**

Statistical Performance Analysis

**목적:** 실제 배차 로그 CSV를 분석하여 기존 세 가지 배차 정책과 팀원의 1185점 최적화 정책 사이에 어떤 성능 차이가 존재하는지 확인한다.

### **비교 대상**

| 정책                        | 주요 특징                 |
| ------------------------- | --------------------- |
| 긴급 주문 우선 (Urgency First)  | 긴급 주문에 우선순위 부여        |
| 가까운 거리 우선 (Nearest First) | AGV와 주문 사이의 이동 거리 중시  |
| 먼저 온 요청 우선 (FCFS)         | 주문 도착 순서 중시           |
| 최적화 정책 (1185점)            | 여러 조건을 결합한 결정나무 기반 배차 |

### **세부 분석**

| 분석 항목         | 주요 내용                           | 시각화 방법               |
| ------------- | ------------------------------- | -------------------- |
| ① 전체 성능 비교    | 평균 대기시간, 긴급 주문 P95, 총비용         | Bar Chart            |
| ② 대기시간 분포     | 평균뿐 아니라 중앙값, 상위 5%, 극단적 지연 비교   | Box Plot, Histogram  |
| ③ 구역별 병목 분석   | RECV, SORT, PICK 등 출발 구역별 지연 비교 | Heatmap, Bar Chart   |
| ④ 혼잡 상황 분석    | 대기 주문 수가 증가할 때 정책별 성능 변화        | Line Chart           |
| ⑤ 긴급·일반 주문 비교 | 긴급 주문 우선 처리에 따른 일반 주문 지연 여부     | Grouped Bar Chart    |
| ⑥ AGV 운영 효율   | AGV별 작업 분배, 유휴 상태, 공차 이동거리      | Histogram, Bar Chart |
| ⑦ 시간대별 성능     | 시뮬레이션 진행에 따른 지연 및 병목 변화         | Time Series          |

### **통계적 검증**

단순한 그래프 비교에 그치지 않고 다음 분석을 고려한다.

- 동일 Seed를 사용하여 네 정책의 성능 비교
- Seed별 성능 차이와 변동성 분석
- 여러 Seed에서의 Paired Comparison
- 평균 성능뿐 아니라 최악의 상황에서의 안정성 평가

단, **Seed 11 하나의 로그만으로 전체 성능의 통계적 우월성을 입증할 수는 없다.** 여러 Seed의 결과가 확보되면 검증 범위를 확장한다.

### **핵심 질문**

- 1185점 정책은 기존 정책의 어떤 문제를 해결했는가?
- 개선 효과가 가장 크게 나타나는 작업 구역은 어디인가?
- 주문이 몰리는 상황에서도 개선 효과가 유지되는가?
- 긴급 주문의 대기시간을 줄이면서 일반 주문의 성능도 유지하는가?
- 최적화 정책에도 여전히 남아 있는 병목은 무엇인가?

**예상 산출물:** Python 분석 코드, 통계 분석 보고서, 비교 그래프, 발표용 성능 분석 슬라이드.
